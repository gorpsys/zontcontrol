# Договорённости проекта, 14.10.2026

> Историческая запись от 14.10.2026; действующие правила — [правила разработки](../agents/development.md).
> Исходный текст ниже сохраняет контекст решения на ту дату.

По запросу владельца взяты правила
[gorpsys/autorepeater PR #36](https://github.com/gorpsys/autorepeater/pull/36),
head 4902aa8168f6f50fb188dc4360775474016027e2. На момент переноса PR открыт;
текст этого head выбран вместо старого master.

Перенесены разделение README/технических инструкций/истории, короткий
AGENTS с индексом, SemVer и аннотированные теги как источник версии,
выпуск по завершённому PR или пакету связанных PR, checks на точный SHA
и контракт Yandex Cloud Functions + GitHub OIDC + Lockbox.

Адаптация: unittest вместо pytest, во время работы — только stdlib, две офлайн-проверки
вместо торгового Sandbox E2E, без резервных вариантов с SDK или vendor-копиями. В исходном
проекте есть setuptools-метаданные: статический 0.1.0 заменён версией из тега;
untagged checkout обозначается 0.0.0.dev0. Этот номер не является выпуском.
На момент этой работы 14.10 Git-репозиторий/remote/теги ещё не создавались.
Состояние и схема версии позже изменены:
[текущая история версий](versioning.md), [итог 16.10](2026-10-16-architecture-implementation.md).

Не переносились финансовые стратегии, тестовые торговые контуры, ресурсные
ID autorepeater и право автоматических управляющих вызовов. Существующий
пакет и reports оставлены на своих путях, чтобы не ломать команды и архивы.
Сырые reports исключены из будущей публикации; выбранные итоги — docs/reports.

Облачный запуск пока планируется. Контракт и шаблон параметров подготовлены,
handler/workflow/resource creation остаются следующими этапами. Поэтому
README не сообщает о работающем облаке. Конкретные ID нужны при переходе
к настройке ресурсов и не выводятся из другого проекта.
