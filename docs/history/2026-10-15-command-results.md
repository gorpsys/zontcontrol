# Результаты команд управления, 15.10.2026

Решение владельца по замечанию №9: обычные синхронные вызовы с различимыми
исходами. Успех — успешный ответ API; ошибка — явное отклонение либо локальная
ошибка до отправки; неизвестный результат — timeout/обрыв после отправки,
когда команда могла исполниться. Автоматического повтора нет.

Дополнительное чтение состояния доступно потребителю, но обязательный
мониторинг каждой команды и сервис фоновых операций не вводятся. Tickets,
operation_id и get_operation, снятые ранее, не возвращаются.

Успех API сброса не доказывает восстановления нагрева; это оценивается по
последующим показаниям. Timeout регистратора означает истечение ожидания
алгоритма и не превращается в отклонение/отмену уже принятых команд.
