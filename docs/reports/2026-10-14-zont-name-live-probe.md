# Натурные проверки строки названия ZONT

14.10.2026, SMART 2.0, device_id=700877. Владелец явно разрешил реальные
тесты строки при сохранении текущего названия как префикса.
Исходное название: `3E7934F4FAF5` (12 ASCII-символов).

## Методика

Запись: POST /api/update_device, только поля device_id и name.
Каждое тестовое значение начинается с исходного названия целиком.
Проверка после записи — чтение через POST /api/devices и GET
/api/widget/v3/devices?device_ids=700877&fields=sensors. Сравниваются точные
строки, а не только ok или длина. Команды отоплению, сбросу, реле, уставкам
и режимам не отправлялись. Каждый блок завершается восстановлением названия
и чтением через оба API. Токен/пароль и полные ответы ЛК не сохраняются.

Время в таблицах и тексте без явного смещения — Москва (UTC+03:00).
Это проверка API, не ограничений поля ввода или отображения в веб-интерфейсе.
В тестах Unicode длина означает число кодовых точек Python, не UTF-16 units
и не количество визуальных символов.

## Длина

Проверены полные длины названия вместе с 12-символьным исходным префиксом:
32, 64, 128, 255, 256, 512, 1024, 2048, 4096, 8192, 16384, 32768 и 65536.
Дополнение — пробел и ASCII-символы x. Во всех 13 случаях запись принята,
полная строка без обрезания совпала при чтении через оба API.

Итого подтверждено не менее 65536 ASCII-символов / байт UTF-8 на название,
из них при текущем префиксе 65524 символа доступны для суффикса.
Верхний предел не найден: значения больше 64 КиБ этим тестом не проверялись.
Пустое название и удаление префикса не проверялись по условию владельца.
В 15:13:53 исходное название после блока длины восстановлено и подтверждено
обоими API.

Дополнительно проверены строки длиной 1024 кодовые точки с кириллическим
суффиксом (2035 байт UTF-8) и с emoji-суффиксом (4057 байт UTF-8). Обе приняты
и прочитаны точно через оба API.

## Итоговое состояние

Всего 27 разных тестовых значений успешно записаны и точно прочитаны через
оба API. В каждом случае сохранён исходный префикс. Последний блок завершён
в 15:14:47: name=`3E7934F4FAF5`, точное совпадение подтверждено полным API
и Widget v3. После этого тестовые записи не выполнялись.

## Ограничение частоты

Первый блок проверок выполнялся слишком часто. После успешной записи/чтения
варианта с U+0000 API вернул HTTP 429. Первая попытка восстановления тоже
попала под лимит. Последующие попытки с паузами восстановили исходное название;
в 15:11:28 точное совпадение подтверждено обоими API.

Дальнейшие тесты ограничены интервалом не менее 2,2 секунды между началами
запросов, включая чтения. Точное правило квоты по одному этому наблюдению
не установлено: не объявлять этот интервал гарантированно допустимой частотой.

## Применимость

Название пригодно как общая строка для небольшого JSON/маркера с сохранением
человекочитаемого префикса. Оно остаётся видимым названием в ЛК. Наличие
строкового хранилища не создаёт атомарного захвата: update_device не получает
условия на прежнее значение, а два клиента могут перезаписать друг друга.
