# Ревью удаления синхронизации управления

> Датированное ревью от 20.10.2026: удаление синхронизации, PR #9.
> Основание — [решение владельца](../history/2026-10-20-remove-synchronization.md);
> текущий [Controller API](../agents/contracts.md#управляющий-api) хранится отдельно.
> Первоначальные вердикты и принятые риски сохранены; это не список нынешних нерешённых проблем.

PR: [#9](https://github.com/gorpsys/zontcontrol/pull/9).
Цель — удалить всю синхронизацию и оставшуюся от неё сложность чтения
и доработки кода. Действующая архитектура — [прямой Controller API](../agents/architecture.md).
Реальные команды, калибровка и деплой в цикл ревью не входили.

## Холодный читатель

Отдельный субагент получил код, документацию, PR и цель упрощения без
контекста переписки. Первый проход нашёл три P2 и три рекомендации:

| Причина | Проверка применимости и исправление |
| --- | --- |
| UUID запусков и цепочка UUIDFactory | Production-потребителей не осталось. Поля instance_id/run_id и генератор удалены из DI, тестов и текущих контрактов. |
| Индивидуальный HTTP-бюджет | Последний production-caller удалён с координацией. timeout_seconds убран; общий настроенный HTTP timeout и проверки времени ответа сохранены. |
| Фабрика consumer-контроллера | Возвращала один общий контроллер. Registry/runtime теперь получают его напрямую; factory создаёт только алгоритм внутри бюджета once. |
| Повторная проверка отмены reset | Между проверками не было работы. Условие разделено на проверку решения и одну проверку отмены. |
| Неиспользуемый maximum в reset | Удалён вместе с поддержкой прежних grant wait/poll. |
| Исторический протокол в reference | Три справочника перенесены в history, ссылки исправлены. Текущие zont-api/anomaly-detection описывают прямое управление. |

При собственной проверке дополнительно удалены закрытие ресурсов из runtime
(один владелец ресурсов — application/registry), параметр fields без callers,
поддержка дрейфа/epoch/NTP в тестовых часах и мелкие остатки импортов/переменных.
Транспорт получает обычный callable clock вместо объекта часов координации.

Повторный холодный проход не нашёл новых существенных замечаний; рекомендация
уточнить название теста свежего контекста принята. Финальную дельту коммита
0d27077 читатель проверил отдельно без новых замечаний.

make check: 298 тестов, четыре installed-only пропуска; lint и Markdown-ссылки
успешны. make package-check: шесть проверок установленного wheel без пропусков.

одного прибора, unknown без повторов, off в finally, таймаута once, отмены,
